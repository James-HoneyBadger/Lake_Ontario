# Lake Ontario BASIC

**Lake Ontario BASIC** is a fully featured, practical, whimsical, and satirical programming language built in the spirit of classic BASIC — infused with Canadian politeness, progressive values, and a **fearless Honey Badger attitude** that takes zero shit from MAGA spin, GOP propaganda, or oligarch intimidation.

In **Lake Ontario**, alternative facts don't compile, universal healthcare protects against runtime crashes, wealth is taxed gracefully into public infrastructure, workers unionize effortlessly, and Honey Badger mode shreds disinformation with zero fear.

### Farcical Policy Statements
- `FAT_CATS_TAX amount`: Issues an absurdly large wealth redistribution levy.
- `DONUT_DIVIDEND amount`: Schedules a donut payout for every public protest.
- `NATIONAL_STOOGE statement`: Publishes a theatrical political spin statement.
- `GREEN_NEW_DEAL goal`: Calls out an ambitious climate and transit policy agenda.
- `RHETORICAL_QUESTION question`: Asks a question with an obviously evidence-based answer.
- `LOONIE_LOOP count`: Generates a whimsical loop of cartoon loonies.
- `SOCIAL_LICENSE name`: Grants approval from unionized beavers and open-source poets.
- `ELECTORATE_PULSE value`: Reports a mock public enthusiasm percentage.
- `NATIONAL_HEALTHCARE`: Alias for `UNIVERSAL_HEALTHCARE` with extra pomp.

### Progressive & Satirical Operators

- `WEALTH_TAX` (`-`): Subtraction or tax deduction.
- `EQUAL_PAY` (`+`): Addition or equitable distribution.
- `PROPORTIONAL_SHARE` (`/`): Division.
- `FAIR_MULTIPLIER` (`*`): Multiplication.
- `POWER_TO_THE_PEOPLE` (`**`): Exponentiation.
- `MAPLE_SYRUP` (`%`): Modulus, with extra Canadian sweetness.
- `MOONSHOT` (`**`): Exponentiation for goal-driven policy wins.

### Boolean & State Literals

- `EVIDENCE_BASED` (`True`): Science-backed truth.
- `ALTERNATIVE_FACT` (`False`): Unsubstantiated MAGA claim evaluating to false.
- `CLASSIFIED_MAR_A_LAGO` (`None`): Missing, hidden, or misplaced variable state.

## 2. Built-in Math, Science & Diversity Functions

### Science, Health & Education
- **`SCIENCE_FACT("topic")`**: Returns peer-reviewed consensus statements on climate, vaccines, evolution, and diversity.
- **`PEER_REVIEWED_SQRT(val)`**: Returns the square root grounded in mathematical proof.
- **`SCIENCE_ROUND(val, decimals)`**: Rounds numbers with scientific accuracy.

### Pro-Worker, Diversity & Social Welfare
- **`HONEY_BADGER_DEBUNK(claim)`**: Shreds propaganda and lies into peer-reviewed dust with zero fear.
- **`HONEY_BADGER_BITE(target)`**: Relentlessly tears apart bad-faith claims and oligarchy threats.
- **`HONEY_BADGER_STRIKE(action)`**: Launches an unyielding worker strike with zero hesitation or fear.
- **`LIVING_WAGE(hours, rate)`**: Calculates income based on fair living wage standards.
- **`UNIVERSAL_BASIC_INCOME(population, grant)`**: Calculates UBI distribution pools.
- **`CARBON_OFFSET(emissions_tons)`**: Calculates green energy dividend funds.
- **`UNIONIZE(workers)`**: Organizes worker lists into bargaining units.
- **`CELEBRATE_DIVERSITY(items)`**: Formats inclusive community collectives with 2SLGBTQIA+, Indigenous, and newcomer representation.
- **`DEFUND_OLIGARCHY(wealth)`**: Cap hoardings and redistributes 95% to social housing.
- **`TAX_THE_BILLIONAIRE(amount)`**: Deducts 90% of fortunes exceeding $1M into public services.
- **`DEBUNK("TEXT")`**: Converts ALL-CAPS MAGA hyperbole into calm, lowercase, CBC-verified facts.
- **`FACT_CHECK_CROWD(claimed)`**: Scales down exaggerated crowd size claims to actual satellite counts.


## 5. IDE and Command Reference

A lightweight Lake Ontario BASIC IDE is available for interactive scripting.

Run it with:

```bash
python3 ide.py
```

The IDE lets you:
- browse example programs
- edit or create `.lo` scripts
- run scripts from the command line
- view the full Lake Ontario BASIC command reference

A complete command and function reference is also available in `COMMANDS.md`.

## Standalone IDE Installation

The standalone IDE can be installed as a Python package from this repository:

```bash
python3 -m pip install .
```

Then launch it with the GUI IDE:

```bash
lake-ontario-ide
```

Or run the bundled launcher directly:

```bash
python3 run_ide.py
```

When the GUI starts, you can edit a script, run it, view output, and watch graphics appear on the canvas. The GUI also supports `TOWN_HALL` prompts in an input dialog.
