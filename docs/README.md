# Lake Ontario BASIC Documentation

This documentation suite covers the Lake Ontario BASIC language, the standalone GUI IDE, interpreter usage, examples, and developer reference.

## Documentation structure

- `docs/getting_started.md` — install, run, and first script
- `docs/language_reference.md` — statement and function reference
- `docs/gui_ide_guide.md` — using the standalone GUI IDE and graphics commands
- `docs/examples_guide.md` — example scripts and learning paths
- `docs/developer_manual.md` — interpreter internals, extension points, and packaging
- `README.md` — main project overview and quick start
