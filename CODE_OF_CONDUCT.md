# Code of Conduct

Lake Ontario BASIC is a project for curious people, language designers, civic technologists, and anyone who enjoys a sharp joke with a solid evidence base. We aim to keep the project welcoming, intellectually honest, and constructive even when the subject matter is political, satirical, or emotionally charged.

This project is not a place for harassment, intimidation, or bad-faith disruption. We welcome disagreement, but not abuse.

## Our expectations

Participants are expected to:

- Be respectful, kind, and constructive in discussion.
- Assume good intent while calling out harmful or misleading ideas clearly.
- Critique code, proposals, and arguments rather than people.
- Keep debates factual, relevant, and anchored in the project’s goals.
- Make space for new contributors, first-time users, and people with different technical backgrounds.
- Focus on what helps the project improve, not on escalating conflict for sport.

## Unacceptable behavior

The following are not acceptable in project spaces, issue threads, pull requests, or community channels:

- Harassment, threats, or intimidation.
- Personal attacks, demeaning language, or discriminatory remarks.
- Repeatedly derailing discussions with provocation or bad-faith arguments.
- Trolling, doxxing, or publicly shaming contributors.
- Posting hateful, extremist, or discriminatory content.
- Abusing project moderation or using the repository as a platform for targeted harassment.

## Scope

This code of conduct applies to:

- all project repositories and contribution spaces
- issue discussions and pull requests
- chat, community channels, and any project-run events
- interactions that affect the project’s community or collaboration

## Enforcement

Project maintainers may take action they consider appropriate, including:

- a warning
- temporary removal from discussion spaces
- a temporary or permanent ban from contributing
- rejection of a pull request or issue comment thread

Enforcement decisions will be made in a way that is fair, proportionate, and consistent with the project’s goals.

## Reporting

If you experience or witness unacceptable behavior, please report it privately to the project maintainer or repository owner. Include as much relevant detail as you can: what happened, where it happened, when it happened, and any supporting context.

Reports will be handled with discretion and seriousness. We will aim to respond promptly and take the minimum action needed to protect the community.

## A note on tone

This project is intentionally satirical, but satire is not a license for cruelty. We can be sharp, funny, and politically pointed without becoming abusive, demeaning, or manipulative.

We protect the spirit of the project by keeping it bold, truthful, and humane.

## Attribution

This Code of Conduct draws on the spirit of widely used open-source community standards, adapted for a project that values evidence, civility, and constructive dissent.
